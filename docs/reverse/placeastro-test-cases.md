**カテゴリ**: API  
**優先度**: 高  
**実装工数**: 1時間  

**テスト目的**: APIの稼働状況を確認する

**事前条件**:
- APIサーバーが起動している

**テスト手順**:
1. `GET /api/placeImages/health` にリクエスト送信
2. レスポンスを確認

**期待結果**:
- HTTPステータス: 200
- レスポンス: `{ success: true, data: "OK" }`

**テストコード例**:
```typescript

});
```
